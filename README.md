# شاعر للخضروات

موقع عربي باتجاه RTL لمتجر خضروات وفواكه وتمور. الواجهة متجاوبة مع الجوال والكمبيوتر، وتضم صفحات أقسام مستقلة وبحثًا وسلة طلبات ورسالة واتساب للتوصيل.

## تشغيل الموقع

افتح `index.html` في متصفح حديث، أو فعّل GitHub Pages على المستودع لعرضه كرابط موقع.

## إعداد المتجر قبل استقبال الطلبات

- غيّر `STORE_PHONE` إلى رقم واتساب المتجر بالصيغة الدولية، من دون `+` أو مسافات.
- غيّر `STORE_ADDRESS` إلى عنوان المتجر.
- راجع الأسعار ورسوم التوصيل والعروض في بيانات المنتجات.

الأسعار ورسوم التوصيل في النسخة الحالية تجريبية. صور المنتجات مستضافة من Unsplash وتحتاج اتصالًا بالإنترنت؛ تظهر رسومات رمزية عند تعذر تحميل أي صورة.
